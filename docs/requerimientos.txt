RF001. El sistema debe permitir registrar usuarios del refugio con su identificación, nombre, correo electrónico y rol (coordinador, veterinario o voluntario).

RF002. El sistema debe permitir a un usuario autenticarse mediante credenciales y habilitar únicamente las funciones correspondientes a su rol.

RF003. El sistema debe permitir registrar el ingreso de un animal rescatado con su nombre, especie, raza, sexo, edad aproximada, origen del ingreso, fecha de ingreso y descripción.

RF004. El sistema debe permitir actualizar la información registrada de un animal.

RF005. El sistema debe permitir registrar un cambio de estado de un animal, indicando el nuevo estado, la fecha del cambio y el usuario responsable.

RF006. El sistema debe permitir registrar la ubicación de un animal en un espacio de alojamiento del refugio, indicando la fecha de asignación.

RF007. El sistema debe permitir consultar los espacios de alojamiento del refugio con su capacidad y su ocupación actual.

RF008. El sistema debe permitir buscar animales aplicando filtros por especie, raza, sexo, edad y estado.

RF009. El sistema debe permitir consultar la ficha integral de un animal, incluyendo su estado actual, su alojamiento, su historial médico, sus solicitudes y sus seguimientos.

RF010. El sistema debe permitir administrar un catálogo de tipos de vacuna, indicando el nombre y la descripción de cada tipo.

RF011. El sistema debe permitir registrar la aplicación de una vacuna a un animal, indicando el tipo de vacuna, la fecha de aplicación y el veterinario responsable.

RF012. El sistema debe permitir registrar un tratamiento médico de un animal, indicando el diagnóstico, la fecha de inicio, la fecha de finalización y el veterinario responsable.

RF013. El sistema debe permitir registrar un adoptante con su identificación, nombre, teléfono, correo electrónico, dirección de residencia, tipo de vivienda y experiencia previa con animales.

RF014. El sistema debe permitir registrar una solicitud de adopción de un adoptante sobre un animal disponible, indicando la fecha de la solicitud.

RF015. El sistema debe permitir registrar la evaluación de una solicitud de adopción, indicando la fecha, el resultado y las observaciones del coordinador.

RF016. El sistema debe permitir registrar la cancelación de una solicitud de adopción por decisión del adoptante, indicando la fecha y el motivo.

RF017. El sistema debe permitir consultar las solicitudes de adopción registradas por un adoptante y las solicitudes asociadas a un animal.

RF018. El sistema debe permitir registrar una adopción a partir de una solicitud aprobada, indicando la fecha de entrega del animal.

RF019. El sistema debe permitir programar las visitas de seguimiento de una adopción, indicando la fecha prevista y el voluntario asignado.

RF020. El sistema debe permitir registrar el resultado de una visita de seguimiento, indicando la fecha de realización y las observaciones sobre el estado del animal.

RF021. El sistema debe permitir registrar la devolución de un animal adoptado, indicando la fecha y el motivo.

RF022. El sistema debe permitir asignar un voluntario como responsable del cuidado de uno o varios animales.
